# Life OS - Personal Habit & Progress Tracking System

## Overview

Life OS is a personal web application designed to track my daily habits, learning, fitness, productivity, and financial progress.

The goal is not just to track habits, but to build a complete personal operating system that helps me stay disciplined and continuously improve.

The application focuses on simplicity, consistency, and meaningful analytics.

---

# Primary Goals

- Build long-term discipline
- Track daily habits
- Track study consistency
- Track income-producing work
- Track health-related habits
- Monitor financial progress
- Generate weekly and monthly reports
- Visualize long-term improvements
- Keep everything inside a single dashboard

---

# Daily Workflow

Every day, preferably around 8 PM, I will open the application and complete my Daily Journal.

The application automatically records:

- Current Date
- Current Time
- Day
- Week Number
- Month
- Journal Created Time
- Journal Submitted Time

I only need to enter my daily values.

After submitting, the dashboard updates automatically.

# Dynamic Habit System

The application should never hardcode habits.

Users should be able to:

- Add new habits
- Delete habits
- Edit habits
- Enable or disable habits
- Change scoring rules
- Change weekly targets
- Change monthly targets

without changing application code.
